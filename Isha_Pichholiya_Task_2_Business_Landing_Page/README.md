# Northside Digital - Responsive Business Landing Page

**Author:** Isha Pichholiya  
**Organisation:** WeIntern Pvt Ltd  
**Assignment:** Week 1 - Task 2

## Project description

A responsive landing page for Northside Digital, a fictional digital agency. The page introduces the business, explains its services and gives visitors a clear route to an enquiry form. The design uses green accents, light backgrounds and a dashboard illustration made with CSS.

## Technologies used

- HTML5 and semantic page sections
- CSS3, custom properties, Flexbox, CSS Grid and media queries
- Vanilla JavaScript
- Google Fonts: DM Sans and Manrope, with browser fallback fonts

## Features

- Navigation bar with links to Home, Services, About and Contact
- Mobile navigation menu that closes after selecting a link
- Hero section with two call-to-action buttons
- Six service cards
- About section and another contact call to action
- Labelled contact form with name, email, optional phone, service and message fields
- Browser-side validation and an on-page confirmation message
- Responsive layouts for mobile, tablet and desktop
- Hover effects and visible keyboard focus styles

Northside Digital is a fictional business for this assignment. The form is a frontend demonstration: it validates entries but does not send or store enquiries. It does not require an email account or backend setup.

## Instructions to run locally

1. Extract the ZIP into a folder.
2. Open `index.html` in a modern browser such as Chrome, Edge or Firefox.
3. Use the navigation and call-to-action buttons to move between sections.
4. Resize the browser to try the mobile menu and responsive service cards.
5. Try submitting the form with empty fields, then with valid details, to see validation and the confirmation message.

No installation, build step or configuration is required. Google Fonts load when an internet connection is available; browser fallback fonts are used otherwise.
